Introduction

Clawix is an open-source, self-hosted multi-agent AI orchestration platform designed for secure AI workflow execution, governance, memory management, and scalable agent collaboration inside isolated Docker containers.

Clawix is designed for:

  • AI consultants building enterprise AI workflows
  • AI enthusiasts experimenting with autonomous agents
  • Junior developers learning AI orchestration and infrastructure
  • Organizations requiring private and governable AI systems

Clawix focuses on production-grade orchestration with:

  • Container-isolated agents
  • Self-hosted deployment
  • Governance and auditability
  • Multi-agent collaboration
  • Multi-provider AI support
  • Persistent memory and workspaces
  • Role-based access control

Yes. Clawix is publicly available as an open-source project under the MIT license.

Core Concepts

A multi-agent orchestration platform enables multiple AI agents to collaborate, delegate tasks, share memory, and execute workflows together.

AI agents are autonomous assistants powered by large language models (LLMs) that can execute tasks, use tools, and coordinate workflows.

Sub-agents are specialized helper agents dynamically created by primary agents to perform delegated tasks independently inside isolated containers.

Swarm orchestration allows multiple AI agents to collaborate in Directed Acyclic Graphs (DAGs), where tasks can run sequentially or in parallel before results are aggregated into a final response.

Heartbeats and cron workflows allow AI agents to execute recurring scheduled tasks such as reminders, monitoring, automation jobs, and periodic reporting.

  3. Run: pnpm run install:clawix

Security, Governance & Permissions

Container isolation prevents:

  • Cross-agent interference
  • Unauthorized file access
  • Resource exhaustion
  • Host-level execution risks

No. Each agent runs inside its own sandboxed Docker container with isolated workspaces and scoped permissions.

Provider API keys and secrets are encrypted using AES-256-GCM encryption and stored securely on the server.

Governance features include:

  • Audit logs
  • Token budgets
  • Structured logging
  • Prometheus metrics
  • Scoped memory controls
  • Role-based access control (RBAC)

RBAC stands for Role-Based Access Control. It manages permissions and access levels for Admin and Developer users.

Clawix currently supports:

  • Admin
  • Developer

Admin users can:

  • Configure AI providers
  • Manage communication channels
  • Create and manage users
  • Configure Telegram integration
  • Manage organization settings and governance policies

Developer users can:

  • Create and manage agents
  • Create sub-agents
  • Execute workflows
  • Use AI communication channels

Developers cannot manage system-wide settings or create Admin accounts.

Yes. Existing Admin users can create additional Admin accounts if required.

Clawix is designed with governance principles aligned to enterprise AI governance practices, including auditability, accountability, operational oversight, and secure AI execution.

Memory, Workspaces & Skills

Clawix supports:

  • Private memory
  • Group memory
  • Organization-wide memory

This enables AI agents to retain contextual knowledge across workflows and teams.

Persistent memory allows AI agents to maintain long-term context, improve continuity, and reduce repetitive prompting.

Persistent workspaces are user-specific directories that survive container restarts and store files, outputs, and project artifacts.

Troubleshooting

Installation failures commonly happen when old Docker volumes still exist while new environment credentials are generated, causing mismatched database credentials.

Remove all containers, volumes, and old environment files before reinstalling:

docker compose -f docker-compose.prod.yml down --volumes --rmi all --remove-orphans

Then rerun:

pnpm run install:clawix

This usually indicates:

  • Database initialization problems
  • Missing POSTGRES_PASSWORD
  • Old Docker volumes conflicting with new environment variables

Check the organization timezone settings inside Clawix. The server timezone and configured application timezone may differ.

No. Users can log in, log out, and switch accounts without restarting Docker services.
